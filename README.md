# Vortrix — shooter d'arène néon pour téléphone

Jeu de tir en arène, vu du dessus, pensé pour le tactile (marche aussi sur ordinateur).
HTML5 pur, sans dépendance : il suffit d'ouvrir `index.html`.

## Contenu
- **15 niveaux** répartis sur 3 mondes (Nébuleuse Azur, Ceinture Pourpre, Noyau Ardent), avec un **boss** aux niveaux 5, 10 et 15.
- **4 difficultés** : Facile, Normal, Difficile, Cauchemar (plus la difficulté est haute, plus on gagne de crédits). La progression est enregistrée séparément pour chaque difficulté.
- **5 armes** à acheter puis à améliorer jusqu'au niveau 5 : Blaster, Dispersion, Rayon laser, Missiles à tête chercheuse, Plasma.
- **6 améliorations** du vaisseau : coque (PV), propulseurs, cadence, puissance, bouclier régénérant, aimant à crédits.
- 7 types d'ennemis (chasseurs, foreurs qui chargent, tireurs, diviseurs, orbiteurs, tanks…).
- Bonus temporaires : tir rapide, dégâts ×2, invincibilité, soin.
- 1 à 3 étoiles par niveau selon les PV qu'il te reste à la fin. Sauvegarde automatique dans le navigateur.

## Commandes
| Téléphone | Ordinateur |
|---|---|
| Glisser à gauche de l'écran : se déplacer | ZQSD / WASD / flèches |
| Glisser à droite de l'écran : viser et tirer | Souris (clic maintenu) |
| Tir automatique sur l'ennemi le plus proche (option) | idem |
| Bouton ⇄ : changer d'arme | Q / E / Tab ou 1 à 5 |
| Bouton II : pause | Échap / P |

## Jouer sur téléphone
1. Activer **GitHub Pages** sur ce dépôt (Settings → Pages → branche, dossier `/`).
2. Ouvrir l'URL sur le téléphone, puis « Ajouter à l'écran d'accueil » pour le jouer en plein écran, comme une application (il fonctionne aussi hors ligne).
